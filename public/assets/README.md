# Assets do Mini Planet

Coloque as artes de jogador e texturas nesta estrutura:

- `public/assets/player/idle/1.png`, `2.png`, `3.png`
- `public/assets/player/walk/1.png`, `2.png`, `3.png`, `4.png`
- `public/assets/player/run/1.png`, `2.png`, `3.png`, `4.png`

O jogo carrega essas imagens como sprites do jogador.

Se quiser adicionar texturas gerais, use:

- `public/assets/textures/<nome>.png`

Exemplo de URL dentro do jogo:

- `/assets/player/idle/1.png`
- `/assets/textures/pixel.png`
